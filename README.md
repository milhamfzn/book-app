# Hotel Room Booking App

A simple fullstack app to **book hotel rooms**. Built step-by-step as a learning project.

---

## What this project is

- **Learning module:** See [LEARNING_MODULE.md](./LEARNING_MODULE.md) for the full course (Phases 1–6).
- **Your roadmap:** See [PROJECT_ROADMAP.md](./PROJECT_ROADMAP.md) for your current phase and next tasks.
- **App goal:** Users can see rooms, pick date/time, and book a room (later: list bookings, maybe log in).

---

## How to run (as you build)

### Phase 1 (HTML/CSS/JS only)
- Open `client/index.html` in your browser (double-click or “Open with Live Server” in VS Code/Cursor).
- No server needed yet.

### Phase 3+ (with backend)
- **Server:** `cd server` then `npm install` and `npm start`.
- **Client:** Open `client/index.html` or run your frontend dev server (e.g. `npm start` in `client/`).
- See README in `server/` and `client/` when you add them.
