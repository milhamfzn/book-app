# Start Here — You're New, That's OK

This folder is your **study** for learning fullstack web development. Your project is a **Hotel Room Booking App**.

---

## What to do first (in order)

1. **Read the module**  
   Open [LEARNING_MODULE.md](./LEARNING_MODULE.md) and read **Phase 1** (don’t skip to the backend).

2. **See your roadmap**  
   Open [PROJECT_ROADMAP.md](./PROJECT_ROADMAP.md). It tells you your current phase and your next 3 tasks.

3. **Install Node.js** (if you don’t have it)  
   Go to [nodejs.org](https://nodejs.org) and download the **LTS** version. You’ll need it later; good to have it now.

4. **Run the starter page**  
   Open the file `client/index.html` in your browser (double-click it, or right‑click → Open with → your browser).  
   You should see “Hotel Room Booker” with a list of rooms and a form. Click **Book** and you’ll get an alert. That’s Phase 1 in action.

5. **Change something small**  
   In `client/style.css`, change a color (e.g. `#0d6efd` to `#28a745`) or the font. Save and refresh the browser. You’ve just done a tiny bit of “frontend.”

6. **Follow the module**  
   Do the “Booking app step” and “Checkpoint” for Phase 1 in [LEARNING_MODULE.md](./LEARNING_MODULE.md). When you’re done, update [PROJECT_ROADMAP.md](./PROJECT_ROADMAP.md) and move to Phase 2.

## Skills you’ll build (big picture)

- **Frontend:** HTML, CSS, JavaScript, then React (or similar).
- **Backend:** Node.js, Express, REST API.
- **Data:** Database (e.g. SQLite or PostgreSQL), basic SQL.
- **Habits:** Git, validation, README, a bit of debugging.

You don’t need to master everything before building. You learn by doing the booking app step in each phase.
